# 🚛 남양주시 화물팀 인허가 안내 초고속 스마트 AI 챗봇

남양주시 자동차관리과 화물팀 실무 매뉴얼(`manual_data/화물운송사업_매뉴얼.md`)을 기반으로, 민원인과 실무자가 복잡한 화물차 인허가 절차를 쉽고 빠르게 안내받을 수 있도록 개발된 초고속 행정 AI 챗봇입니다.

---

## 🌟 핵심 특징

1. **🔒 강력한 보안 & API 키 은닉 (서버 사이드 프록시)**
   - 브라우저 개발자 도구(F12)나 네트워크 탭, 소스코드에 Groq API Key가 절대 노출되지 않도록 Node.js Express 보안 백엔드를 거쳐 통신합니다.
   - `.env` 및 `.gitignore`를 통해 소스 제어 시 키 유출을 원천 방지합니다.

2. **⚡ Groq LPU 엔진 기반 초고속 실시간 스트리밍 (0.3초 내 응답)**
   - SSE(Server-Sent Events) 방식을 적용하여 생성되는 텍스트가 즉각 타이핑되듯 화면에 표시됩니다.
   - 46개 세부 섹션 자동 인덱싱 RAG를 탑재하여 질문과 밀접한 행정 매뉴얼 섹션만 정밀 주입하므로, 토큰 한도 초과(413) 없이 초당 수백 토큰 속도로 답변합니다.

3. **🎨 신뢰감 높은 공공 스마트 행정 UI/UX**
   - 세련된 슬레이트 다크 모드 & 클린 라이트 모드 완벽 지원.
   - 자주 묻는 민원 6대 퀵 질문 칩 원클릭 질의 지원.
   - 복잡한 행정 서류 표(Table), 단계별 번호 목록 마크다운 실시간 렌더링.
   - 답변 원클릭 클립보드 복사 기능.

## 🚀 빠른 실행 방법

### 1. 패키지 설치 (최초 1회)
터미널(PowerShell 또는 명령 프롬프트)에서 아래 명령어를 실행합니다:
```bash
npm.cmd install
```

### 2. 챗봇 서버 실행
```bash
node server.js
```

### 3. 브라우저 접속
웹 브라우저를 열고 아래 주소로 접속합니다:
👉 **`http://localhost:3080`**
